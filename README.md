# Netflix Movies & TV Shows — EDA

A beginner-friendly EDA project exploring content trends, ratings, country distribution, and growth patterns on Netflix using Python and pandas.

## Objective
To explore the Netflix Titles dataset and answer the following questions:
- What is the split between Movies and TV Shows on Netflix?
- Which audience ratings dominate the platform?
- Which countries produce the most Netflix content?
- How has Netflix grown in content addition over the years?
- What genres are most popular on Netflix?

## Dataset
[Netflix Shows — Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)

## Tools Used
- Python (pandas, matplotlib, seaborn)
- Google Colab

## Project Structure
- `Netflix_EDA.ipynb` — Main notebook with full EDA, visualisations, and insights

## Skills Demonstrated
- Data loading and inspection with pandas
- Missing value identification and handling
- Data type correction (datetime conversion)
- Univariate and bivariate analysis
- Data visualisation with matplotlib and seaborn
- Business insight generation from raw data

## Key Findings
- Netflix library is ~70% Movies vs 30% TV Shows
- TV-MA is the most common rating — Netflix targets adult audiences
- USA, India, and UK are the top content producing countries
- Netflix peaked in content addition in 2019, declining post-COVID
- International Movies, Dramas and Comedies are the top genres
