# Netflix Movies & TV Shows — EDA

Exploratory Data Analysis on the Netflix Titles dataset from Kaggle.

## Tools Used
- Python (pandas, matplotlib, seaborn)
- Google Colab

## Key Findings
- Netflix library is ~70% Movies vs 30% TV Shows
- TV-MA is the most common rating — Netflix targets adult audiences
- USA, India, and UK are the top content producing countries
- Netflix peaked in content addition in 2019, declining post-COVID
- International Movies, Dramas and Comedies are the top genres

## Dataset
[Netflix Shows — Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
